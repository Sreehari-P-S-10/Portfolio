# Sreehari P S - Portfolio

Welcome to the source code of my personal developer portfolio. This is a modern, single-page application built to showcase my projects, experience, and skills as a Full Stack Developer.

## 🚀 Tech Stack

* **Framework:** React 19
* **Build Tool:** Vite 8
* **Styling:** Tailwind CSS v4
* **Language:** TypeScript
* **Animations:** Custom CSS and Intersection Observer Hooks
* **Deployment:** Vercel

## ⚙️ Running Locally

To run this project on your local machine, ensure you have Node.js and `pnpm` installed.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sreehari-P-S-10/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   pnpm install
   ```

3. **Start the development server:**
   ```bash
   pnpm run dev
   ```

4. **Build for production:**
   ```bash
   pnpm run build
   ```
